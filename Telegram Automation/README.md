# Foodi Cafe Telegram Bot

A smart restaurant order bot built with n8n, 
Google Sheets, and AI.

## Features
- AI-powered order taking via Telegram
- Google Sheets integration for order tracking
- Live inventory from Google Sheets
- Multi-language support
- Auto order saving with Order ID
- AI-powered responses using Gemini

## Workflow
![Workflow](assets/Telegram%20Automate.JPG)

## Tech Stack
- n8n (workflow automation)
- Telegram Bot API
- Google Sheets API
- Google Gemini AI

## Setup
1. Clone this repo
2. Import workflow JSON to n8n
3. Add your own credentials
4. Publish and go live
